Boolean Crop Condition Classifier

Rule-Based Crop Suitability Decision System · Interactive Simulator

Problem Statement

Crop growth depends on several environmental conditions such as temperature, humidity, soil moisture, rainfall, soil pH and sunlight. This project uses Boolean decision logic to determine whether the given conditions are suitable for crop growth.

Software Solution

The system accepts environmental values from the user and checks them against predefined acceptable ranges. Boolean AND conditions are used to classify the overall crop condition as Suitable or Not Suitable.

Boolean Decision Logic

Crop Condition = Temperature OK AND Humidity OK AND Soil Moisture OK AND Rainfall OK AND Soil pH OK AND Sunlight OK

If all conditions are TRUE → Suitable

If any condition is FALSE → Not Suitable
